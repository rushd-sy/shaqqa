User Stories   &&   Acceptance Criteria:
1. As a Buyer, I want to see the seller's Agent badge, so that I can trust the seller before contacting them.
Given the buyer wants to verify the seller's trustworthiness
When the buyer visits the seller's profile
Then the buyer can see the agent badge on the seller's profile
 
2.As a Seller, I want to receive an Agent badge quickly and easily, so that I can become trustworthy to buyers.
Given the seller does not have an agent badge
When the seller submits their documents through the platform
Then the seller receives the agent badge after admin approval without needing to complete multiple sales
 
3.As a Buyer, I want to see the ratings and badges on the listing, so that I can know other customers' reviews about the seller.
 Given there are ratings and reviews from other customers
When the buyer reads the reviews and sees the ratings on the listing
Then the buyer gains knowledge of other customers' opinions about the property  



////////////////////////////////



Edge Cases:
*
- If the seller has no agent badge => display "This seller has no badge" to the buyer
- If the seller's badge has been removed by admin => display "Badge Revoked" to the buyer 
**
- If the seller has no ratings => display "No ratings yet" to the buyer
- If the seller has no reviews => display "No reviews yet" to the buyer
